# Getting Started

This tutorial walks you through building your first application with Fabrique.

> **Work in progress** — This tutorial is under construction.

## Prerequisites

- Rust 1.75 or later
- PostgreSQL database
- Basic knowledge of SQL and async Rust

## What You'll Build

A simple application that manages an inventory of products, demonstrating:
- Defining models
- Querying data
- Inserting and updating records
- Using factories for testing
